# Gestão de Oficina de Equipamentos Móveis

Este projeto nasceu de um problema que conheço bem no dia a dia da manutenção: informações espalhadas, acompanhamento manual e dificuldade para enxergar rapidamente o que está acontecendo com cada equipamento e cada ordem de serviço.

A ideia foi transformar parte dessa rotina em um fluxo digital mais organizado. Como não sou desenvolvedora de software, construí e evoluí a aplicação com apoio do Lovable e de IA, partindo principalmente do meu conhecimento do processo: o que precisava ser registrado, quais regras o sistema deveria seguir e o que realmente seria útil para quem trabalha na operação.

## O que o sistema reúne

- dashboard para acompanhamento da operação;
- cadastro e acompanhamento de equipamentos;
- ordens de serviço corretivas e preventivas;
- programação e acompanhamento das atividades de manutenção;
- fluxos diferentes para PCM, inspetores e mecânicos;
- autenticação e controle de acesso;
- área administrativa.

## Tecnologias utilizadas

React, TypeScript, Vite, Supabase e ferramentas de desenvolvimento assistido por IA.

## Meu papel no projeto

Meu foco foi transformar a necessidade operacional em regras e funcionalidades: desenhar os fluxos, definir o comportamento esperado, testar com situações do dia a dia, encontrar problemas e ir ajustando a aplicação.

Ainda estou aprendendo desenvolvimento e quero entender cada vez melhor a parte técnica por trás do que construo. Por isso mantenho este projeto no portfólio: ele mostra uma solução funcional, mas também mostra meu processo de aprendizado usando tecnologia para resolver um problema que eu realmente conheço.

## Sobre esta versão

O repositório é uma versão para demonstração e portfólio. Informações operacionais, credenciais e dados que não devem fazer parte de uma versão pública não são o objetivo deste projeto.

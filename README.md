# Workshop Equipment Tracker

Aplicação web para gestão de manutenção e acompanhamento operacional de equipamentos, desenvolvida como projeto prático de digitalização de processos de oficina.

## Visão geral

O sistema centraliza etapas do fluxo de manutenção em uma única aplicação, apoiando o acompanhamento de equipamentos, ordens de serviço e atividades da equipe técnica.

O projeto foi construído com apoio de ferramentas de IA e desenvolvimento assistido (vibe coding), partindo da definição do problema, regras de negócio, fluxos, testes e validação funcional.

## Principais funcionalidades

- Dashboard para acompanhamento operacional
- Gestão e catálogo de equipamentos/frota
- Fluxos específicos para PCM, inspetores e mecânicos
- Registro e acompanhamento de ordens de serviço corretivas e preventivas
- Planejamento e acompanhamento de atividades de manutenção
- Autenticação e controle de acesso
- Área administrativa

## Tecnologias

- React
- TypeScript
- Vite
- Supabase
- Lovable / desenvolvimento assistido por IA

## Objetivo do projeto

Transformar rotinas operacionais de manutenção em fluxos digitais mais estruturados, reduzindo registros dispersos e facilitando o acompanhamento das atividades e das informações necessárias à tomada de decisão.

## Sobre esta versão

Este repositório é apresentado como demonstração técnica e de portfólio. A documentação pública deve utilizar apenas informações genéricas ou fictícias e não tem como objetivo expor dados operacionais, credenciais ou informações confidenciais de organizações, clientes ou colaboradores.

## Aprendizados

O desenvolvimento deste projeto envolveu levantamento de necessidades, estruturação de regras de negócio, desenho de fluxos, validação de dados e testes iterativos. O uso de IA generativa apoiou a construção e evolução da aplicação, enquanto a definição das funcionalidades e a validação do comportamento do sistema foram orientadas pelo problema operacional a ser resolvido.
